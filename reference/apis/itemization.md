# Itemization, Weapons & Marketplace

Inventories and items (`/UnrealEngine.com/Itemization` + `/Fortnite.com/Itemization`), customizable weapons (Armory), the item/weapon prefab catalogs, and Marketplace commerce.

> **Digest = source of truth.** Exact signatures live in your build's generated digests; `grep` them. See `../uefn/toolchain.md`. (Verified against build 42.00.)

## Itemization — `/UnrealEngine.com/Itemization`

**Call-convention trap: the mutation APIs are `<transacts>` returning `result(...)` — call with `()`, not `[]`.** "Fails" in their doc comments means an error `result`, not Verse failure. Only `GetParentInventory[]`, `IsEquipped[]`, `Drop[]`, `PickUp[]`, `GetMaxSlots[]` are `<decides>`.

- **`inventory_component`** (`<final_super>`): `[3800+]` `AddItem(Item:entity, ?AllowMergeItems:logic)` (this inventory only) / `AddItemDistribute(...)` (may enter sub-inventories) `<transacts>:result(add_item_result, []add_item_error)`; `RemoveItem(Item)` (incl. descendant inventories) `<transacts>:result(remove_item_result, []remove_item_error)`. Queries: `GetItems()`/`GetItems(castable_subtype(item_component))<reads>:[]entity` (this inventory only); `FindItems()<reads>:generator(entity)` `[2930+]` / `FindItems(Type)<reads>:[]entity` (incl. descendant inventories — note the asymmetric return types); `GetInventories():[]inventory_component` / `FindInventories():generator(...)` `[2930+]`; `GetEquippedItems():[]entity`. Events `AddItemEvent`/`RemoveItemEvent` (`listenable(*_item_result)`), `EquipItemEvent`/`UnequipItemEvent` — fire on this inventory, then **propagate up to all ancestor inventories**. Precheck extensions `[3800+]`: `CanAddItem(...)`/`CanAddItemDistribute(...)`/`CanRemoveItem(...)` `<transacts>:result(false, []*_error)`.
- Result payloads: `add_item_result{AddedItems:[]entity, ModifiedItems:[]tuple(entity, int)}` (tuple = item + previous stack size); `remove_item_result{Inventory, RemovedAmount:int, RemovedItems, ModifiedItem:?tuple(entity, int)}`.
- **`item_component`** (`<final_super>`; "an entity with this is an item"): `GetParentInventory()<decides><reads>`, `IsEquipped()<decides><reads>`; `[3800+]` `Equip()`/`Unequip()<transacts>:result(false, []*equip_item_error)` (+ `CanEquip()`/`CanUnequip()` extensions); `Drop[]`/`Drop[WorldTransform]` and `PickUp[Inventory]` (`<transacts><decides>` — these DO use `[]`); `ChangeInventoryEvent:listenable(change_inventory_result{ItemComponent, PreviousInventory:?, CurrentInventory:?})`, `ChangeEquippedEvent:listenable(change_equipped_result{ItemComponent, IsItemEquipped})`; `@editable Categories:[]item_category` (`item_category` is `class<castable><concrete><unique>`).
- **Scene events** steer inventory choice and veto ops (subclass the `<computes>` error classes, call `Event.AddError(...)` in `OnReceive`): `find_inventory_event` (sent down to choose — set `var ChosenInventory:?inventory_component` + `ChosenInventoryPriority:float`), `add_item_query_event`/`remove_item_query_event`/`equip_item_query_event`/`unequip_item_query_event` (veto; sent **up from the inventory** to ancestors and **down from the item entity** to children). (Scene events: `scene-graph.md`.)

## `/Fortnite.com/Itemization`

- **`fort_inventory_component`** (base of all Fortnite inventories, default HUD/behavior): `GetMaxSlots()<decides><reads>:int`. Finals: `fort_inventory_weapon_hotbar_component` (weapons/gadgets; `SetMaxSlots(int)`), `fort_inventory_build_hotbar_component`, `fort_inventory_harvest_tool_component`, `fort_inventory_trap_component`, `fort_inventory_resources_component`, `fort_inventory_ammo_component`, `fort_inventory_currencies_component`. BR-style HUD only shows for the default configuration — custom inventories need Verse UI.
- **`FortniteItemCategories.*`**: `WorldItem`/`Currency`/`Trap`/`Ammo`/`Resource`/`WeaponMelee`/`WeaponRanged`. **`FortniteRarities.*`** `[4000+]`: `Common`/`Uncommon`/`Rare`/`Epic`/`Legendary`/`Mythic`/`Exotic` (`rarity` + subclasses live in `/Verse.org/SceneGraph`; `rarity_component`).
- **`fort_item_pickup_interactable_component`** `[4040+]` (extends `basic_interactable_component`): interact-to-pick-up. Owning entity needs an `item_component` + `mesh_component`; the interacting agent needs a subentity carrying an `inventory_component`; `GetInteractorInventory(Agent)<transacts><decides>:inventory_component`.

## `/Fortnite.com/Armory` — customizable weapons

- **`fort_weapon_component`** (`<abstract><final_super>`, base): `IsHolstered:logic`, `HolsterChangedEvent:listenable(tuple())`.
- **`fort_trace_weapon_component`**: the tuning surface for pistol/AR/SMG/shotgun templates. All knobs are `var<private>` `@editable`s **read directly but mutated via `SetX(...)` setters**: `Damage` [0–1000], `EnvironmentalDamageMultiplier`, `RangeDamageMultiplier:[]fort_range_damage_multiplier` (struct `{Range, DamageMultiplier}`), `MaxRange`, `FireRate` [0–25], `ReloadTime`, `MagazineCapacity` [1–1000], `ShotAmmoCost` [0–10]; spread: `ExpansionRateMultiplierPerShot`, `CooldownRateMultiplierOverTime`, `IdleSpreadMultiplier` + per-stance `Moving/Crouching/Sliding/Sprinting/AimDownSightSpreadMultiplier`; `RecoilMultiplier`/`AimDownSightRecoilMultiplier`; FX/sounds: `MuzzleOffset`/`MuzzleFlash`/`BulletTracer`/`EjectionPortOffset`/`BulletShells` (`?particle_system`), `WeaponFireSound`/`EquipSound`/`AimingDownSightsStart/EndSound`/`ReloadStart/Insert/EndSound`/`OutOfAmmoSound` (`[]sound_wave`).
- **`fort_multi_trace_weapon_component`** (extends trace): `BulletsPerShot` [1–20].
- Prefabs + meshes: `pistol_/assault_rifle_/sub_machine_gun_/shotgun_` × `_template` (`class<concrete><final>(entity)`) / `_mesh` (`mesh_component`).

## `/Fortnite.com/Items` & `/Fortnite.com/Weapons` — prefab catalogs

Flat reference catalogs of `class<final><concrete>(entity)` prefabs. Naming scheme: **`<BaseName>_<Source>_<Season>_<Rarity>`** — Source ∈ `BR` (vast majority) / `OG` / `Creative` / `Ballistic`; Season ∈ `CHxSy` / `CHxMSy` / `PreSeason` / `V1`; Rarity ∈ `Common`…`Exotic`. The same base item recurs per season/rarity (e.g. three `CeilingZapper_*`, both `_Rare`), so **`grep` the digest for the base name first**, then pick source/season/rarity.

## `/Fortnite.com/Marketplace` — in-island transactions

Real-money (V-Bucks) commerce: `entitlement` subclasses sold via `entitlement_offer`/`bundle_offer`, `BuyOffer`/`ShowOffersDialog` purchase UIs, grant/consume/query APIs, and the in-world `offer_interactable_component`. Full reference (incl. the base-`entitlement`-type runtime traps): **`marketplace.md`**.
