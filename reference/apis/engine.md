# Engine Utilities (`/UnrealEngine.com`)

The remaining `/UnrealEngine.com` surface: diagnostics, curves, the deprecated SpatialMath, JSON, WebAPI, shapes, and `SortBy`. (Widgets: `ui.md`. Itemization: `itemization.md`. `/UnrealEngine.com/Abilities`: `abilities.md`. `/UnrealEngine.com/ControlInput` (input events plumbing): `input.md`. LLM NPCs: `conversations.md`. Quests: `progression.md`.)

> **Digest = source of truth.** Exact signatures live in your build's generated `UnrealEngine.digest.verse`; `grep` it. See `../uefn/toolchain.md`. Verified against build 42.00.

- **`Temporary/Diagnostics`**: `log`/`log_channel`/`log_level` (`Debug`/`Verbose`/`Normal`/`Warning`/`Error`) — `log{Channel := my_channel}` with `log.Print(msg, ?Level)` (`<computes>`; string or `diagnostic` overloads; `DefaultLevel` field) and `PrintCallStack(?Level)`. `debug_draw`/`debug_draw_channel` (`DrawSphere`/`DrawBox`/`DrawCapsule`/`DrawCone`/`DrawCylinder`/`DrawLine`/`DrawArrow`/`DrawPoint`/`DrawText`, with `?Color`/`?Thickness`/`?Duration`/`?DrawDurationPolicy` (`SingleFrame`/`FiniteDuration`/`Persistent`); every `Draw*` has overloads for BOTH `vector3` types — Verse.org and Temporary — so no conversion needed; `ShowChannel`/`HideChannel`/`ClearChannel` (all users, per channel) and instance `Clear()`).
- **`Temporary/Curves`**: `editable_curve.Evaluate(Time:float):float` — designer-authored float curves via `@editable`.
- **`Temporary/SpatialMath`** (deprecated X/Y/Z, still required by `fort_character` and older devices): `vector3`/`rotation`/`transform` plus `vector2`/`vector2i` (with full `+ - * /` operators, `DotProduct`, `Distance[Squared]`, `Lerp`, `MakeUnitVector[]`, `Length[Squared]`, `ToVector2`/`ToVector2i[]`, `IsFinite[]`/`IsAlmostZero[]`/`IsAlmostEqual[]`). Rotation surface: `MakeRotation(Axis, AngleRadians)`, `MakeRotationFromYawPitchRollDegrees`, `IdentityRotation`, `ApplyYaw/Pitch/Roll` (local), `ApplyWorldRotationX/Y/Z`, `ApplyLocalRotationY/Z`, `RotateBy`/`UnrotateBy`, `RotateVector`/`UnrotateVector`, `MakeShortestRotationBetween` (rotations or vectors), `Slerp` (`<decides>`), `Distance`/`AngularDistance`, `GetAxis`/`GetAngle`/`GetYawPitchRollDegrees`, `GetLocalForward/Right/Up`, `Invert`. `transform`: `TransformVector[NoScale]`. `DegreesToRadians`/`RadiansToDegrees`. **The `From*` bridge overloads convert BOTH directions** between this and `/Verse.org/SpatialMath`: `FromVector3`/`FromScalarVector3`/`FromRotation`/`FromTransform`. (The two-namespace trap: `scene-graph.md`.)
- **`Conversations`** `[4000+]`: LLM NPCs — `persona_component` (personality/voice/interruption rules, say/hear/moderation events), `ai_session.Prompt` into typed structs `[4100+]`, `RegisterAction` tool-binding `[4120+]`, player conversation targeting, `ai_error` hierarchy. Full reference: `conversations.md`.
- **`Progression`** `[4110+]`: quests — `basic_quest` auto-complete/auto-reward, objectives, rewards (incl. Marketplace entitlements), quest-UI presentation `[4200+]`. Full reference: `progression.md`.
- **`(UnrealEngine.com:)JSON`**: `Parse(str)[]→value` (`<transacts><decides>`), `value.AsObject[]:[string]value`/`AsArray[]`/`AsInt[]`/`AsFloat[]`/`AsString[]`/`AsNull[]`. Parse-only — no serializer.
- **`BasicShapes`**: `cube`/`sphere`/`plane`/`cone`/`cylinder` (all `mesh_component` subclasses).
- **`(UnrealEngine.com:)Assets`**: `SpawnParticleSystem(asset, position, ?rotation, ?delay)→cancelable` — overloads take either SpatialMath `vector3`/`rotation`.
- **`WebAPI`**: derive a **non-public** `client_id` subclass (its Verse class path is the backend config key — treat it as a private key), `MakeClient(id)<converges>:client`, `client.Get(path)<suspends>:response`, downcast to `body_response` for `.GetBody():string`. GET only.
- **`SortBy(Array, Less(:t,:t)<computes><decides>:void)<computes>:[]t`** (`/UnrealEngine.com/Temporary`) — THE generic array sort; stable; native spelling despite the Temporary namespace. Reach for it before hand-rolling. Limit: `Less` must be `<computes>` — a comparator reading mutable state (sort by current health) is rejected; only then hand-roll a `<transacts>` sort.
