# `/Verse.org` Native API

The language's standard library — the API layer that belongs to Verse itself, not to the engine or Fortnite. (The other two layers, `/UnrealEngine.com/*` and `/Fortnite.com/*`, live in `reference/apis/`.)

> **Digest = source of truth.** Exact signatures live in your build's generated `Verse.digest.verse`; `grep` it. See `../uefn/toolchain.md`. Verified against build 42.00. `[N+]` marks `@available{MinUploadedAtFNVersion := N}` gates.

## `/Verse.org/Verse` — core

- **`Print(Message:string|message|diagnostic, ?Duration:float = 2.0, ?Color:color = White)<transacts>`**. For logs prefer `/UnrealEngine.com/Temporary/Diagnostics`'s `log`.
- **`Err(Message:string)<computes>:false`** — unrecoverable runtime error; yields bottom type.
- **Math** (all `/Verse.org/Verse`): `Abs`, `Min`, `Max`, `Clamp` (int + float; float versions treat `NaN > +Inf`), `Floor`/`Ceil`/`Round`/`Int` (float→int, `<decides>` — fail on `NaN`/`±Inf`), `Sqrt`, `Pow`, `Exp`, `Ln`, `Log(B,X)`, `Sin`/`Cos`/`Tan`/`ArcSin`/`ArcCos`/`ArcTan`/`ArcTan(Y,X)`, hyperbolic `Sinh`/`Cosh`/`Tanh`/`ArSinh`/`ArCosh`/`ArTanh`, `Lerp(From,To,T)`, `Sgn` (int + float), `Mod[a,b]`/`Quotient[a,b]` (`<decides>`, Euclidean — `Mod` sign follows divisor), `(X).IsFinite[]`, `(X).IsAlmostZero[Tol]`, `IsAlmostEqual[X,Y,Tol]`, `PiFloat`, `Inf`, `NaN`. **`Floor(R:rational)` parens vs `Floor[F:float]` brackets.**
- **`GetSecondsSinceEpoch()<reads>:float`** — Unix time; constant within a transaction.
- **Strings/arrays:** `ToString(int|float|char|string)`, `Concatenate(Arrays:[][]t)` (flattens), `Join(Strings, Sep)`; array extension methods (all return a *new* array): `Find[Elem]:int`, `Insert[Index, Elems]`, `RemoveElement[Index]`, `Remove[Start, Stop]` (range, Stop exclusive), `RemoveFirstElement[Elem]`, `RemoveAllElements(Elem)`, `ReplaceElement[Index, New]`, `ReplaceFirstElement[Old, New]`, `ReplaceAllElements(Old, New)`, `ReplaceAll(Pattern, Replacement)`, `Slice[Start, Stop]` / `Slice[Start]`.
- **Events & async interfaces:** `event(t)` (`Signal`/`Await`; FIFO resume; also bare `event()` = `event(tuple())`); interfaces `signalable(t)`, `subscribable(t)` (`Subscribe(cb)<transacts>:cancelable`), `listenable(t)` (= awaitable+subscribable — most engine events), `cancelable` (`.Cancel()<transacts>`). (`awaitable`/`task` live in `/Verse.org/Concurrency`, below.) **Not in the 42.00 digest:** `sticky_event`, `subscribable_event`, `cancelable_container` — don't reference them; the `subscribable_event` wrapper in `../patterns.md` §2 is user code.
- **`result(success_type, error_type)`** `[3800+]` — `MakeSuccess(v)`, `MakeError(e)`, `.GetSuccess[]`, `.GetError[]`.
- **Marker interfaces:** `disposable` (`Dispose`), `invalidatable(disposable)` (`IsValid[]`), `enableable` (`Enable`/`Disable`/`IsEnabled[]`), `showable` (`var Show:logic`).
- **`modifier(t)`** (`Evaluate(InValue:t)<reads>:t`) and **`modifier_stack(t)`** (`AddModifier(m, Position:rational)→cancelable`, `Evaluate` applies in position order, `FirstPosition`/`LastPosition`) `[4100+ experimental]` — composable transform pipelines (used by camera modifier stacks).
- **`message`** (localized text; `Localize(Msg)<reads>:string`, `Join(Messages, Sep)` `[4100+]`), `diagnostic` (`ToDiagnostic(Value:any)`; `+` concatenates diagnostic/string), `locale`.
- **`Easing`** submodule `[4100+ experimental]`: `CubicBezier(X1,Y1,X2,Y2)` (returns a function), `Linear`/`Ease`/`EaseIn`/`EaseOut`/`EaseInOut` (`(:float)<reads>:float`).
- **`classifiable_subset(t)`** `[experimental]` — hierarchy-aware type set (`MakeClassifiableSubset`, `Contains[]`/`ContainsAll[]`/`ContainsAny[]` `[3800+]`, `FilterByType`, `+` union); details in `language.md` → Advanced types.

## `/Verse.org/Simulation`

- **`agent`** (`class<unique>(entity)`), **`player`** (`class(agent)`, `<persistent>`, a `weak_map` key; `IsActive[]` — using an inactive player as a module-scoped `var weak_map` key is a **runtime error**), **`team`**, **`session`** (`GetSession()<reads>:session`; one instance **per round** today, documented as possibly becoming per-game — don't rely on round-locality; `.Environment()` `[3800+]` → `Edit`/`Private`/`Live`).
- **`Sleep(Seconds:float)<suspends>`** (`0.0` = next tick; `Inf` = forever/cancel-only; `< 0.0` = complete immediately without yielding), `GetSimulationElapsedTime()<transacts>:float`.
- **`Tags`** submodule: `tag` (`class<abstract><castable>`), `has_tags` (`AddTag(t)→tag_key`, `RemoveTag[key]`, `RemoveAllTags[type]`, `RemoveAllTagsExcept[type|types]`, `ContainsTag[type]`, `ContainsAllTags[types]` (empty → succeeds), `ContainsAnyTag[types]` (empty → fails)), `tag_key`, `tag_view` (`Has`/`HasAny`/`HasAll` — these match **parent tags** hierarchically), `tag_search_criteria` (`RequiredTags`/`PreferredTags`/`ExclusionTags`/`SortType`).
- **`@editable`** attribute family lives here: `editable` (`ToolTip:message`, `Categories:[]message`), `editable_number(t)`/`editable_slider(t)` (`MinValue`/`MaxValue`, spinbox/slider deltas), `editable_text_box` (`MultiLine`, `MaxLength`), `editable_vector_number(t)`/`editable_vector_slider(t)` (per-component min/max, preserve-ratio/normalize buttons), `editable_container` (`AllowReordering`).

## `/Verse.org/SpatialMath` (current — Forward/Left/Up, right-handed)

- **`vector3{Forward:=, Left:=, Up:=}`** (persistable), **`rotation`**, **`transform{Translation:=, Rotation:=, Scale:=}`** (applied scale→rotation→translation).
- **Make rotations:** `MakeRotationRadians(Axis, Angle)`/`MakeRotationDegrees` `[3600+]` (axis-angle), `MakeRotationFromYawPitchRollRadians`/`...Degrees`, `MakeRotationFromEulerRadians`/`...Degrees` `[3600+]`, `IdentityRotation()`, `MakeShortestRotationBetween(V1, V2)`, `Slerp(From, To, Ratio)`.
- **Inspect rotations:** `(R).GetForwardAxis/GetLeftAxis/GetUpAxis()`, `GetYawPitchRoll{Radians,Degrees}()`, `GetEuler{Radians,Degrees}()` `[3600+]`, `GetAxis()`/`GetAngle{Radians,Degrees}()` `[3600+]`, `Invert()`, `(R).IsFinite[]`; `Distance(R1,R2)` (0..1) and `AngularDistance{Radians,Degrees}(R1,R2)` `[3600+]`; compose with `R1 * R2`, apply with `V * R`.
- **Vectors:** full component-wise `+ - * /` (+ scalar `*`/`/`, prefix `-`), `DotProduct`, `CrossProduct` `[3600+]` (right-handed; legacy `CrossProductLeftHanded` also exists — pick the right one), `Distance`/`DistanceSquared`, `DistanceForwardLeft`/`DistanceSquaredForwardLeft` (2-D, ignores `Up`), `(V).Length()/LengthSquared()/LengthForwardLeft()/MakeUnitVector()/IsFinite[]/IsAlmostZero[Tol]`, `IsAlmostEqual[V1,V2,Tol]`, `Lerp`, `ReflectVector(Direction, SurfaceNormal)`, `V * transform`, `DegreesToRadians`/`RadiansToDegrees`, `ToString` overloads. See `../apis/scene-graph.md` for the **two SpatialMath namespaces** and `From*` converters.

## Other `/Verse.org` modules

- **`Colors`**: `color{R:=,G:=,B:=}` (ACES 2065-1 linear, persistable) with `+ - *` operators (color×color, color×scalar) and `/` (`<decides>`); `MakeColorFromSRGB(floats)`/`MakeColorFromSRGBValues(ints 0-255)`/`MakeColorFromHex(string)`/`MakeColorFromHSV`/`MakeColorFromTemperature`, reverse `MakeSRGBFromColor`/`MakeHSVFromColor`; `NamedColors.*` (CSS names); `color_alpha`, `MakeColorAlpha(R,G,B,?A)`, `Over[CA1,CA2]` (alpha compositing).
- **`Assets`**: `mesh`, `material`, `texture`, `sound_wave`, `particle_system`, `animation_sequence`, `input_action(t)`, `input_mapping`, `has_icon` (`var Icon:texture`).
- **`Random`**: `GetRandomFloat(Lo,Hi)`, `GetRandomInt(Lo,Hi)` (both `<transacts>`, cryptographically secure, bounds inclusive and order-agnostic), `Shuffle(Arr)`.
- **`Input`** `[4000+]`: `GetPlayerInput(Player)<transacts><decides>:player_input` → mappings on/off per player, `GetInputEvents(input_action(t)):input_events(t)` (detection→activation event flow), input-method/device queries, viewport↔world bridging `[4100+]`. **Full stack — including `/UnrealEngine.com/ControlInput`, the built-in mapping catalogs, and the asset types — in `../apis/input.md`.**
- **`Concurrency`**: `awaitable(payload)` (`Await()<suspends>`; bare `awaitable()` = `awaitable(void)`), `task(t)` (`class<abstract><final>(awaitable(t))` — only `Await` is public; no public `Cancel`).
- **`AgentGroup`** `[4000+]`: `agent_group(member_info)` (`class<unique>`) — `GetMemberMap()<reads>:[agent]member_info`, `AddMember(Agent, Info)`/`RemoveMember(Agent)` → `result(void, add/remove_member_error)`, events `AddMemberEvent`/`RemoveMemberEvent`/`MemberInfoChangeEvent : listenable(tuple(agent, member_info))`; `member_info_interface` marks your info class; `agent_group_interface(member_info)` for consumers.
- **`Progression`** `[experimental]`: `quest` (`Complete()` idempotent, `IsComplete[]`, `JoinEvent`/`AbandonEvent:listenable(quest_membership)`, `CompleteEvent:listenable(quest)`), `quest_collection` (`JoinQuest(Quest, Participant, Info)`/`AbandonQuest` → `result(void, []errors)`; `Quests`/`Participants` membership maps; the same three events), `quest_participant` / `agent_quest_participant` (`Agent:agent`), `quest_participant_info` (`Contributes`/`Observes`/`Receives:logic`). (The auto-completing `basic_quest` machinery is `/UnrealEngine.com/Progression` — `../apis/engine.md`.)
- **`Timeline`** `[4200+]` (NEW in 42.00): abstract building blocks for time-indexed content — `timeline_element` (`class(cancelable)` — cancel to remove), `timeline_element_point` (`var Time:float` (`@editable`, ±Inf ok, NaN ignored), `SetTime`), `timeline_element_span` (`var BeginTime` (default 0.0) / `var EndTime` (default Inf), `SetRange(Begin, End)`; requires `Begin <= End`, no NaN). Only the element types live here — the containers that consume them are engine-side (grep your digest for `timeline_element` consumers).
- **`Presentation`**: `description_component` / `has_description` (`Name`/`Description`/`ShortDescription:message`) — covered with the other built-in components in `../apis/scene-graph.md`.
- **`Chat`** `[4000+]`: `voice_channel(member_info)` (`class<final>(chat_channel(...))`, ≤80 members; `Name:message`, `Group:agent_group_interface`), `has_voice_member_info` (`var CanBroadcast:logic`); `entity.AddChatChannel(Channel)` / `RemoveChatChannel` → `result(void, add/remove_channel_error)` (register on the **simulation entity**; text chat max 100), `entity.GetVoiceChannels()`. Note: docs mention `text_channel` but no public class exists in the 42.00 digest.
- **`Predicts`** / **`Native`**: `epic_internal` plumbing (prediction runtime, `@import_as`) — nothing callable.
- **`/Verse.org/SceneGraph`** — the entity/component model — is covered in `../apis/scene-graph.md` (also home of `rarity`/`rarity_component`).
